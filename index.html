Works

Live 3D model from the game

Packets of Long Ago (昔々のパケットたち)

Vue.js 3 / Three.js / Blender

A 3D learning game that explains networking basics (IP addresses, routers, switches) through the folktale of Momotaro. I came up with the concept and built the frontend: 3D rendering, collision handling and the UI logic. It won the Concept Award at a school exhibition and was shown at CEATEC 2026.

LighTouch

Kotlin (Android) / ESP32-C3 / PN532 / BLE

A smart light that works like a lock: it only switches on when a registered NFC tag is held to it. An Android app connects over BLE for setup and key management, and settings can only be changed while a physical button is pressed.

GitHubSlides

E-Paper Calendar

M5Paper (C++) / Python, FastAPI / Docker, Nginx

An IoT calendar for M5Paper that shows the latest events from Google Calendar. The server renders the calendar as an image, and the device uses ETag caching to skip redraws when nothing has changed, which saves power.

GitHubSlides

AWS Drift Detection and Slack Alerts

Terraform / AWS (CloudTrail, EventBridge, SNS, SQS, Lambda, KMS) / Python

An event-driven system that detects manual changes to AWS resources managed with Terraform (configuration drift) and notifies Slack right away. It has no screen: CloudTrail events flow through EventBridge, SNS and SQS to a Lambda function that posts the alert.
