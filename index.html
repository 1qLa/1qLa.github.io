AWS Drift Detection and Slack Alerts

Terraform / AWS (CloudTrail, EventBridge, SNS, SQS, Lambda, KMS) / Python

Terraformは、AWSコンソールで手作業された変更(例: セキュリティグループの開放)に、次に terraform plan を実行するまで気づけません。このシステムは、そうした手動変更をすぐに検知してSlackに通知し、管理外の変更を早く見つけます。

  1. CloudTrailAPI操作を記録
  2. EventBridge変更を絞り込む
  3. SNS通知を振り分ける
  4. SQSためて再送に備える
  5. Lambdaメッセージを整える
  6. Slackチームに通知

Lambdaの環境変数に置いたSlack Webhook URLは、AWS KMSで暗号化しています。
